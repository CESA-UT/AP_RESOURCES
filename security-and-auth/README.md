# Security و Authentication

این پروژه امنیت enterprise نمی‌خواهد، اما از شما می‌خواهد حداقل‌های خطرناک را رعایت نکنید. مهم‌ترین نمونه‌اش ذخیره‌نکردن plain password است.

## موضوع‌های مهم

- هش‌کردن رمز عبور
- اعتبارسنجی ورودی
- نگه‌نداشتن password خام
- طراحی ساده برای login و change password
- محدودکردن آسیب خطاهای کاربری

## چه زمانی سراغ این بخش بیاییم؟

- قبل از نهایی‌کردن register و login
- وقتی می‌خواهید فرمت ذخیره‌سازی کاربران را ببندید
