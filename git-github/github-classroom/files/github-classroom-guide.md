# راهنمای کوتاه GitHub Classroom

این خلاصه برای فهم workflow تحویل پروژه در Classroom است.

## assignment

- assignment می‌تواند فردی یا گروهی باشد
- برای این تمرین، assignment گروهی مهم است

## repository گروه

- بعد از قبول assignment و ساخت تیم، repository گروه ساخته می‌شود
- همان repository مرجع تحویل فازهاست

## چند نکته مهم

- deadline مهم است
- version قابل اجرا باید روی branch اصلی باشد
- اگر template repository استفاده شده، ساختار اولیه از آن می‌آید

## برای این تمرین

- همه اعضا روی repository گروه کار می‌کنند
- commitهای معنادار و push به‌موقع مهم است
