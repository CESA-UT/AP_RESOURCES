# Git و GitHub

این بخش برای workflow واقعی کار گروهی روی همین تمرین است.

## نیازهای مهم این تمرین

- `clone`
- `commit`
- `branch`
- `merge`
- `pull request`
- حل `conflict`
- نگه‌داشتن نسخه stable روی `main` یا `master`
- مشارکت در همین مخزن منابع

## چه زمانی سراغ این بخش بیاییم؟

- وقتی گروه تشکیل داده‌اید و می‌خواهید بدون خراب‌کردن کار همدیگر جلو بروید
- وقتی می‌خواهید فازها را تمیز تحویل بدهید
- وقتی PR یا merge conflict برایتان مبهم است
