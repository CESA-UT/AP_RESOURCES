- موضوع: commit hygiene
- سطح: مقدماتی
- زمان تقریبی مطالعه: ۱۰ تا ۱۵ دقیقه

- عنوان: Commit Standards
- موضوع: commit messages
- سطح: مقدماتی تا متوسط
- زمان تقریبی مطالعه: ۸ تا ۱۲ دقیقه

- مثال مرتبط با تمرین: نوشتن commitهایی مثل `fix(auth): handle empty password` یا ثبت merge conflict با پیام سازگار.
