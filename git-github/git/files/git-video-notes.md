# یادداشت ویدیوهای Git

این فایل برای زمانی است که خود ویدیوهای بیرونی به‌راحتی در دسترس نیستند.

## ویدیو اول

- repository چیست
- stage چه نقشی دارد
- commit دقیقاً چه چیزی را ثبت می‌کند

## ویدیو دوم

- remote repository
- فرق `pull` و `push`
- `origin` و `upstream`

## ویدیو سوم

- branch
- merge
- reset
- restore

## پیشنهاد استفاده

- قبل از کار گروهی ویدیو اول و دوم
- قبل از merge جدی یا حل conflict ویدیو سوم
