# GitHub

این بخش برای قابلیت‌های collaboration روی خود GitHub است، نه خود Git.

## چه زمانی سراغ این بخش بیاییم؟

- وقتی می‌خواهید `pull request` باز کنید
- وقتی review و merge conflict روی GitHub برایتان مبهم است
- وقتی می‌خواهید از branch اصلی پروژه بهتر محافظت کنید
