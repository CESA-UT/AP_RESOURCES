# منابع GitHub

### GH-101

- عنوان: About pull requests
- موضوع: pull request
- سطح: مقدماتی
- زمان تقریبی مطالعه: ۷ دقیقه
- پیش‌نیازها: branch
- چه زمانی باید این را بخوانیم؟ قبل از اولین PR گروه
- خلاصه کوتاه: PR هسته اصلی review و merge روی GitHub است.
- مثال مرتبط با تمرین: هر feature قبل از رفتن به `main` در یک PR بررسی شود.
- لینک یا فایل منبع: [github-collaboration-guide.md](./files/github-collaboration-guide.md)

### GH-102

- عنوان: About merge conflicts
- موضوع: merge conflicts
- سطح: مقدماتی
- زمان تقریبی مطالعه: ۶ دقیقه
- پیش‌نیازها: branch و merge
- چه زمانی باید این را بخوانیم؟ وقتی PR شما merge conflict خورده است.
- خلاصه کوتاه: توضیح می‌دهد merge conflict دقیقاً از چه نوع تغییراتی به وجود می‌آید.
- مثال مرتبط با تمرین: دو نفر همزمان یک بخش از `SocialNetwork.cpp` را عوض کرده‌اند.
- لینک یا فایل منبع: [github-collaboration-guide.md](./files/github-collaboration-guide.md)
- نویسنده/اضافه‌کننده: curated
- وضعیت بررسی: بررسی شده
- ارتباط با تمرین: مستقیم
- استفاده از AI: خیر

### GH-103

- عنوان: Resolving a merge conflict on GitHub
- موضوع: conflict resolution
- سطح: مقدماتی
- زمان تقریبی مطالعه: ۷ دقیقه
- پیش‌نیازها: PR و conflict
- چه زمانی باید این را بخوانیم؟ وقتی conflict شما از نوع ساده line-by-line است.
- خلاصه کوتاه: برای conflictهای ساده می‌شود مستقیم روی GitHub هم resolve کرد.
- مثال مرتبط با تمرین: تغییرات متنی ساده در README یا فایل‌های md این repository.
- لینک یا فایل منبع: [github-collaboration-guide.md](./files/github-collaboration-guide.md)
- نویسنده/اضافه‌کننده: curated

- ارتباط با تمرین: مستقیم
