# Build System

این بخش به دانشجو کمک می‌کند پروژه را قابل build، قابل تحویل و قابل اجرا نگه دارد.

## موضوع‌های مهم

- `Make` و `CMake`
- ساختار پوشه‌بندی پروژه C++
- جداکردن `include/` و `src/`
- اضافه‌کردن library
- build روی سیستم‌های مختلف در حد نیاز پروژه

## چه زمانی سراغ این بخش بیاییم؟

- از همان اول پروژه
- وقتی ساختار فایل‌ها به‌هم ریخته یا build تکرارپذیر نیست
- وقتی قرار است dependency جدید مثل `SQLite` یا GUI اضافه شود
