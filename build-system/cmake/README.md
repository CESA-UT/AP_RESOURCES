# CMake

برای بیشتر گروه‌ها، `CMake` گزینه استانداردتر و قابل‌دفاع‌تری برای این تمرین است.

## چه زمانی سراغ این بخش بیاییم؟

- از همان اول پروژه
- وقتی تعداد فایل‌ها و testها زیاد می‌شود
- وقتی dependency مثل `SQLite`، `Qt` یا `GoogleTest` اضافه می‌کنید
