# SQLite

اگر پروژه شما relationهای بیشتری پیدا کرده، یا integrity و concurrency برایتان مهم‌تر شده، SQLite گزینه جدی‌تری است.

## چه زمانی سراغ این بخش بیاییم؟

- وقتی فایل‌های ساده شروع کرده‌اند شلوغ شوند
- وقتی query یا رابطه‌ها زیاد شده‌اند
- وقتی درباره چند اجرای همزمان نگران هستید
