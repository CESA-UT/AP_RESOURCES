# ذخیره‌سازی داده

این تمرین از فاز اول تا سوم مستقیم به ذخیره‌سازی وابسته است. پس این بخش فقط درباره theory نیست؛ درباره تصمیم‌های عملی پروژه شماست.

## سؤال‌های اصلی این بخش

- فایل متنی ساده کافی است یا نه؟
- `CSV`، `JSON` یا `SQLite` کدام مناسب‌تر است؟
- داده‌ها را چطور serialize کنیم؟
- رابطه بین user، post، comment و like را چطور ذخیره کنیم؟
- بعد از بارگذاری دوباره، referenceها را چطور وصل کنیم؟

## چه زمانی سراغ این بخش بیاییم؟

- وقتی می‌خواهید برای فاز اول persistence طراحی کنید
- وقتی روابط داده‌ای پروژه‌تان پیچیده‌تر شده‌اند
- وقتی بین سادگی فایل و نظم دیتابیس مردد هستید
