# راهنمای JSON و Flat Files

این خلاصه برای وقتی است که می‌خواهید بدون dependency سنگین، persistence پروژه را راه بیندازید.

## چه وقت این مسیر خوب است؟

- فاز اول
- data model هنوز خیلی پیچیده نشده
- می‌خواهید سریع‌تر featureها را کامل کنید

## پیشنهاد طراحی

- objectها را با `id` ذخیره کنید
- relationها را با `id`های دیگر نگه دارید
- مستقیم pointer یا آدرس حافظه را ذخیره نکنید

## الگوی write سالم

1. داده را به فایل موقت بنویسید
2. write را کامل کنید
3. فایل موقت را جایگزین فایل اصلی کنید

این الگو بهتر از overwrite مستقیم فایل اصلی است.

## الگوی load

- اول بازشدن فایل را چک کنید
- اگر فایل وجود ندارد، state خالی ولی سالم بسازید
- اگر parse خراب شد، خطای واضح بدهید و داده خراب را بی‌صدا نادیده نگیرید
