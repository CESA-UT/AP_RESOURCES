# اجرای همزمان و سلامت داده

در فاز سوم، تمرین صریحاً می‌گوید دو اجرای همزمان ساده باید بتوانند با داده خراب‌نشده کار کنند. این بخش برای همین requirement است.

## موضوع‌های مهم

- معنی واقعی requirement اجرای همزمان در این تمرین
- refresh و reload
- جلوگیری از overwrite ناسالم فایل
- انتخاب بین سادگی و robustness
- سناریوهای تست برای دو اجرای همزمان

## چه زمانی سراغ این بخش بیاییم؟

- وقتی persistence شما کار می‌کند و می‌خواهید آن را پایدارتر کنید
- قبل از تحویل نهایی فاز سوم
