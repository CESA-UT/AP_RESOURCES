# اجرای همزمان در این تمرین یعنی چه؟

این requirement معمولاً از چیزی که در نگاه اول به‌نظر می‌رسد ساده‌تر است.

## این تمرین چه چیزی نمی‌خواهد؟

- real-time update
- server push
- distributed system
- multi-user network app کامل

## این تمرین چه چیزی می‌خواهد؟

- دو اجرای ساده برنامه بتوانند با داده خراب‌نشده کار کنند
- اگر یکی چیزی ذخیره کرد، دیگری بعد از reload آن را ببیند
- saveها فایل یا database را ناسالم نکنند

## اگر از فایل استفاده می‌کنید

- قبل از save، state را دوباره load یا merge کنید اگر لازم است
- در فایل موقت بنویسید و بعد replace کنید
- data را با `id` نگه دارید تا reconnect کردن ساده‌تر شود

## اگر از SQLite استفاده می‌کنید

- concurrency پایه را به خود SQLite بسپارید
- transactionها را کوتاه و مشخص نگه دارید
- روی design schema ساده بمانید
