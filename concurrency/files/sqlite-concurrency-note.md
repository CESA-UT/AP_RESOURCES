# SQLite و اجرای همزمان ساده

اگر پروژه شما از SQLite استفاده می‌کند، بخش بزرگی از دغدغه همزمانی فایل‌محور کمتر می‌شود.

## برای این تمرین چه چیزی مهم است؟

- دو اجرای ساده برنامه بتوانند با یک database مشترک کار کنند
- writeها atomic و سالم بمانند
- بعد از reload، داده جدید دیده شود

## پیشنهاد عملی

- transactionها را کوتاه و مشخص نگه دارید
- هر operation مهم مثل create-post یا add-comment را در یک flow مشخص اجرا کنید
- از schema ساده و idمحور استفاده کنید

## چرا این مفید است؟

- locking و commit behavior را خود SQLite مدیریت می‌کند
- نسبت به فایل متنی خام، ریسک خراب‌شدن state کمتر است
