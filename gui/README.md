# GUI

در خود تمرین، GUI اختیاری است. پس این بخش باید دانشجو را سریع به تصمیم برساند، نه اینکه او را وارد یک جنگ frameworkها کند.

## چه چیزهایی اینجا مهم‌اند؟

- مقایسه خیلی ساده `Qt` و `ImGui`
- این‌که هرکدام چه زمانی مناسب‌تر هستند
- راه‌اندازی اولیه
- مثال کوچک مرتبط با نمایش feed، login یا profile

## چه زمانی سراغ این بخش بیاییم؟

- وقتی هسته منطقی پروژه تقریباً شکل گرفته
- وقتی می‌خواهید تصمیم بگیرید GUI اصلاً ارزش دارد یا نه
