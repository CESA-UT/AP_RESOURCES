# طراحی نرم‌افزار و معماری

این بخش از دل خود specification بیرون آمده است. چون در تمرین بارها روی طراحی تمیز، کلاس‌بندی مناسب و توسعه‌پذیری تأکید شده.

## سؤال‌های اصلی

- چه کلاس‌هایی داشته باشیم؟
- مسئولیت هر کلاس کجاست؟
- `main` چقدر باید لاغر بماند؟
- relation بین `User`، `Post`، `Comment` و manager چطور باشد؟
- برای فازهای بعدی چطور از اول راه را باز بگذاریم؟

## چه زمانی سراغ این بخش بیاییم؟

- قبل از شروع پیاده‌سازی فاز اول
- وقتی کلاس‌ها شروع کرده‌اند بیش‌ازحد بزرگ شوند
- وقتی feature جدید اضافه می‌کنید و همه‌چیز به همه‌چیز وصل شده است

## فایل‌های این بخش

- [resources.md](./resources.md): فهرست و توضیح کوتاه منابع
- [ranking.md](./ranking.md): رتبه‌بندی منابع این topic
- [template.md](./template.md): قالب افزودن منبع جدید
- [files/](./files/): فایل‌های واقعی مثل `pdf`، `epub` و `md`
