# مدل‌سازی اولیه `MinSocial`

این note برای وقتی است که هنوز کد زیادی ننوشته‌اید و می‌خواهید موجودیت‌ها را تمیز مشخص کنید.

## موجودیت‌های پایه

- `User`: شناسه، نام کاربری، password hash، تاریخ عضویت، تنظیمات پایه
- `Profile`: نام نمایشی، bio، avatar اختیاری
- `Post`: شناسه، نویسنده، متن، زمان، وضعیت ویرایش
- `Comment`: شناسه، نویسنده، متن، زمان، پست مقصد
- `SocialNetwork` یا `SystemManager`: orchestration عملیات اصلی

## پیشنهاد عملی برای شروع

- relationها را با `id` نگه دارید، نه pointer خام
- data model را برای فاز اول کوچک نگه دارید
- اگر چیزی هنوز لازم نیست، از روز اول داخل class نگذارید

## یک اسکلت سالم برای فاز اول

- `User` و `Profile` را از هم جدا کنید اگر می‌خواهید profile later قابل توسعه باشد
- `Post` را مستقل نگه دارید و فقط `authorId` نگه دارد
- `SocialNetwork` مسئول register/login/search/create-post باشد
- persistence را در یک لایه یا چند تابع مشخص جمع کنید، نه در همه کلاس‌ها
