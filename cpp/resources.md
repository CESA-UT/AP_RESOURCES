### CPP-101

- عنوان: C++ Core Guidelines
- موضوع: طراحی نرم‌افزار، Modern C++، memory management، style guide
- سطح: متوسط / پیشرفته
- زمان تقریبی مطالعه: مطالعه کامل بسیار طولانی — برای هر بخش ۱۵ تا ۴۵ دقیقه
- پیش‌نیازها: آشنایی با syntax زبان ++C، کلاس‌ها، pointer، reference، constructor/destructor، STL
- چه زمانی باید این را بخوانیم؟
  وقتی می‌خواهید کد C++ تمیز، حرفه‌ای، قابل نگهداری و نزدیک به استانداردهای واقعی صنعت بنویسید. مخصوصاً هنگام طراحی کلاس‌ها، مدیریت حافظه و معماری پروژه.

- خلاصه کوتاه:
  مجموعه‌ای از guideline های رسمی و بسیار معروف برای نوشتن C++ مدرن که توسط افراد اصلی دنیای C++ مثل Bjarne Stroustrup و تیم توسعه زبان تهیه شده. این منبع فقط syntax یاد نمی‌دهد؛ بلکه توضیح می‌دهد «چطور باید فکر کنید» و چرا بعضی الگوها خوب یا خطرناک هستند.

- مثال مرتبط با تمرین:
  برای پروژه MinSocial این منبع مخصوصاً در این بخش‌ها مفید است:
  - طراحی کلاس‌های `User` و `Post`
  - جلوگیری از memory leak
  - رعایت Rule of Three/Five/Zero
  - استفاده صحیح از `const`
  - طراحی ownership بین کلاس‌ها
  - جلوگیری از giant class در `SocialNetwork`
  - مدیریت صحیح resource ها و dynamic array ها

  https://github.com/isocpp/CppCoreGuidelines

### CPP-102

- عنوان: The C++ Programming Language (3rd Edition)
- موضوع: زبان ++C، طراحی نرم‌افزار، OOP، memory management
- سطح: متوسط / پیشرفته
- زمان تقریبی مطالعه: بلندمدت — چند هفته تا چند ماه بسته به عمق مطالعه
- پیش‌نیازها: آشنایی با مبانی برنامه‌نویسی، syntax پایه ++C، توابع، کلاس‌ها و pointer
- چه زمانی باید این را بخوانیم؟
  وقتی می‌خواهید درک عمیق‌تری از خود زبان ++C، فلسفه طراحی آن و روش صحیح استفاده از قابلیت‌های زبان پیدا کنید. این کتاب بیشتر مناسب زمانی است که از مرحله مقدماتی عبور کرده‌اید و می‌خواهید حرفه‌ای‌تر کدنویسی کنید.

- خلاصه کوتاه:
  یکی از کلاسیک‌ترین و مهم‌ترین کتاب‌های ++C که توسط خالق زبان، Bjarne Stroustrup نوشته شده. این کتاب نگاه عمیقی به طراحی زبان، مدیریت حافظه، abstraction، object-oriented programming و ویژگی‌های اصلی ++C دارد و هنوز هم یکی از منابع مرجع مهم برای یادگیری اصولی ++C محسوب می‌شود.

- مثال مرتبط با تمرین:
  برای پروژه MinSocial این کتاب در بخش‌های زیر کاربرد زیادی دارد:
  - طراحی ساختار کلاس‌های اصلی مثل `User` و `Post`
  - مدیریت حافظه و جلوگیری از memory leak
  - طراحی سیستم‌های قابل توسعه
  - پیاده‌سازی صحیح constructor و destructor
  - درک ownership و object lifetime
  - رعایت Rule of Three
  - طراحی ماژولار و جداسازی مسئولیت‌ها
