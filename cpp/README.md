# C++

این بخش برای چیزهایی است که مستقیم در پیاده‌سازی `MinSocial` لازم می‌شوند؛ نه برای یادگیری کامل زبان از صفر.

## در این تمرین بیشتر به چه چیزهایی نیاز دارید؟

- طراحی `class` و جداسازی مسئولیت‌ها
- `constructor` و `destructor`
- مدیریت حافظه و ownership
- `Rule of Three`
- `STL` مثل `vector`، `string`، `unordered_map`، `optional`
- خواندن و نوشتن فایل
- `exception handling`
- جداکردن `.h` و `.cpp`
- اگر خواستید طراحی امن‌تر داشته باشید: `smart pointer`

## چه زمانی سراغ این بخش بیاییم؟

- وقتی نمی‌دانید یک موجودیت مثل `User` یا `Post` را چطور مدل کنید
- وقتی بین raw pointer و `smart pointer` مردد هستید
- وقتی با کپی‌شدن ناخواسته داده‌ها یا memory leak مواجه شده‌اید
