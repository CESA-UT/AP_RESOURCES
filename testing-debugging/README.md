# Testing و Debugging

در specification صریحاً آمده که پروژه باید پایدار، بدون crash و تا حد امکان بدون warning باشد. این بخش برای همین است.

## موضوع‌های مهم

- سناریوهای تست برای فازهای مختلف
- تست واحد برای بخش‌های حساس
- تست دستی برای flowهای کاربری
- `assert`
- ابزارهای debug
- بررسی warning و crash

## چه زمانی سراغ این بخش بیاییم؟

- از همان فاز اول
- قبل از merge هر feature مهم
- وقتی bugها شروع کرده‌اند به تکرار شدن
