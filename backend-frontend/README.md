# Backend و Frontend با C++

بعضی گروه‌ها ترجیح می‌دهند به‌جای یک app محلی ساده، یک backend با C++ داشته باشند و از یک frontend وب یا جداگانه برای UI استفاده کنند.

این مسیر برای حل تمرین قابل استفاده است، اما برای بیشتر گروه‌ها مسیر ساده‌تری نیست. پس آن را به‌عنوان یک انتخاب آگاهانه ببینید، نه default.

## چه زمانی سراغ این بخش بیاییم؟

- وقتی گروه شما عمداً backend/frontend را انتخاب کرده است
- وقتی می‌خواهید API-based design داشته باشید
- وقتی می‌دانید complexity این مسیر بیشتر است و برایتان قابل مدیریت است
