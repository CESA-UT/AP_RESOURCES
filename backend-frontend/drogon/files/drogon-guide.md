# راهنمای کوتاه Drogon

`Drogon` برای backend جدی‌تر و feature-rich‌تر مناسب است.

## چه وقت خوب است؟

- وقتی backend برایتان بخش اصلی کار شده
- وقتی dependency و setup بیشتر مشکلی ندارد

## برای این تمرین

- از scope پروژه راحت عبور می‌کند
- فقط اگر گروه عمداً این complexity را انتخاب کرده سراغش بروید

## مزیت

- امکانات بیشتر
- controller و database support آماده‌تر

## هزینه

- setup و dependency بیشتر
- برای خیلی از گروه‌ها از نیاز تمرین سنگین‌تر است
