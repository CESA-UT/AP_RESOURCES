# راهنمای کوتاه Crow

`Crow` یک microframework سبک برای web service در C++ است.

## چه وقت خوب است؟

- وقتی backend سبک می‌خواهید
- وقتی routeهای ساده HTTP کافی هستند

## برای این تمرین

- route برای register/login
- route برای گرفتن feed
- route برای create post

## مزیت

- lightweight
- syntax ساده‌تر نسبت به بعضی گزینه‌های سنگین‌تر

## هزینه

- همچنان complexity backend+frontend را دارید

## منبع‌های اصلی برای نگهداری

- Crow home
- Crow Linux setup
