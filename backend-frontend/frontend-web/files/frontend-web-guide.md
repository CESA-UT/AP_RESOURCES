# راهنمای frontend وب برای backend مبتنی بر C++

اگر backend را با C++ ساخته‌اید، ساده‌ترین frontend همراه معمولاً HTML/CSS/JS سبک است.

## `fetch()`

- برای GET و POST کافی است
- response را می‌توانید به text یا JSON تبدیل کنید

## JSON در frontend

- `JSON.parse` و `JSON.stringify` پایه کار هستند
- قرارداد responseها را از اول ساده نگه دارید

## برای این تمرین

- login request
- گرفتن feed
- ارسال post
- دریافت profile

## پیشنهاد

- frontend را بی‌دلیل پیچیده نکنید
- اگر هدف اصلی‌تان AP است، backend+frontend را فقط وقتی بروید که تیم آماده complexity آن باشد
