# Frontend Web

اگر backend شما با C++ نوشته می‌شود، ساده‌ترین frontend همراه معمولاً HTML/CSS/JS سبک با `fetch()` است.

## چه زمانی سراغ این بخش بیاییم؟

- وقتی backend HTTP دارید
- وقتی می‌خواهید بدون framework سنگین frontend، فقط API را مصرف کنید
